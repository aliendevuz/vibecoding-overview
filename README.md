# Programming Overview & Samples

Dasturlash asoslari va turli tillarda namunalar to'plami.

## Loyiha tarkibi:
- `hello.py` — Python tilida eng sodda "Hello, World!" dasturi
- `dars1.py` — Python 1-dars: `print`, o'zgaruvchilar, arifmetika va shart tekshirish (`if/else`)
- `main.py` — Python amaliy namuna: talabalar baholash tizimi (OOP, class, funksiyalar va ro'yxatlar)
- `hello.php` — PHP tilida "Hello, World!" namunasi
- `hello.erl` — Erlang tilida "Hello, World!" moduli

## Qanday ishga tushiriladi?
```bash
# Python
python hello.py
python dars1.py
python main.py

# PHP
php hello.php
```
